these is true:

1. You have written permission from the author to redistribute the theme, or
2. You have replaced it with a cursor theme that carries a redistribution

`craft-rice` only reads this tarball at install time. Removing it makes the
installer skip the cursor step cleanly; see `lib/assets.sh`.
