# Wallpapers — provenance and license

These ten pixel-art wallpapers were collected from public image galleries
(originally an Imgur album). The individual artists are not identified in the
files, and no license is stated.

**No permission to redistribute these images has been granted.**

## Before publishing

Do not publish this directory in a public repository or release until one of
these is true:

1. You can identify each artist and have their written permission, or
2. You have replaced the collection with wallpapers that carry a redistribution
   license.

`craft-rice` copies whatever is in this directory at install time. Removing the
files makes the installer skip the wallpaper step cleanly; see
`lib/assets.sh`. Users can always drop their own images into
`~/.local/share/backgrounds/craft-rice/` after installing.
