## License status

The archive contains no `LICENSE`, `COPYING`, `README` or author file, and the
GNOME-Look listing does not state a license. The icons are redistributed here
unmodified, but **no permission to redistribute them has been granted.**

## Before publishing

Do not publish this directory in a public repository or release until one of
these is true:

1. You have written permission from the author to redistribute the theme, or
2. You have replaced it with an icon theme that carries a redistribution
   license (for example Papirus, Adwaita or Breeze).

`craft-rice` only reads this tarball at install time. Removing it makes the
installer skip the icon step cleanly; see `lib/assets.sh`.
